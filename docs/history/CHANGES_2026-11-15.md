# Changes on 15 Nov 2026 (after commit 8c68aee)

What changed, where, and how each item was checked. Nothing here is committed yet.

## 1. Facts that still need checking no longer reach later steps

A fact marked "Check" (read from a weak scan or matched approximately) is now left out of the money
calculation, the hearing, the agent, the outcome estimate and the complaint draft until the buyer
confirms it. Facts matched exactly on a text layer count as before.

- Rule in one place: `USABLE` / `is_usable` in `backend/app/buyer/facts.py`.
- Applied in `hearing/inputs.py`, `agent/tools.py`, `insights/draft.py`, `api/insights.py`, `api/cases.py`.
- The case answer carries `facts_to_check`; the Facts page and the step rail show it.
- Test: `test_a_fact_to_check_is_left_out_until_the_buyer_confirms_it`.

## 2. Deleting a case or a single document

- `DELETE /api/v1/cases/{id}`: the case, its files, page text, search chunks and embeddings, facts,
  answers, questions asked, hearing and agent runs.
- `DELETE /api/v1/cases/{id}/documents/{doc}`: the file, its text, chunks and the facts read from it.
- Website: "Delete" on the case list and on the Documents page, asked twice in place.
- "Add documents" on the Documents page (before, documents could only be added when creating a case).
- Tests: three in `tests/test_case_lifecycle.py`; live: `scripts.e2e_check lifecycle` (20 of 20).

## 3. The page as filed, with the passage marked on it

- `GET .../pages/{n}/image`: a PNG of the uploaded page (`backend/app/buyer/page_view.py`).
- `GET .../pages/{n}/highlight?start=&end=`: rectangles for a character span of the stored text.
  Returned only when the page's text layer, rebuilt character by character, equals the stored text.
  For OCR pages and photos it returns `null` and the screen says so: no highlight is better than a
  wrong one.
- Facts page: tabs "Page as filed" and "Text we read".
- Tests: text PDF gives rectangles; a scan gives a picture and no highlight.

## 4. The public example shows a real run

The hand-written example (invented orders, benches, percentages and holdings) is removed:
`frontend/lib/demo-case.ts`, `facts-view.tsx`, `questions-form.tsx`, `not-built.tsx` and the example
branch of every case page.

- `backend/scripts/export_example.py` records the API's own answers for a demo case into
  `frontend/lib/example-snapshot.json` and the page pictures into `frontend/public/example/pages/`.
- `frontend/lib/http.ts` answers every request for case `demo` from that recording. The example
  therefore uses exactly the pages a real case uses, works signed out, and is read-only.
- The buyer and the documents are fictional. The past orders, quotes, counts and money figures are
  what the system produced on 15 Nov 2026. Where it produced "insufficient precedent", the example
  shows that.
- To re-record after a change: `python -m scripts.export_example --case <demo case id>`.

## 5. Agent interest figures were mislabelled (bug fix)

`calculate_interest` in `backend/app/agent/tools.py` returned principal plus interest under the name
`delay_interest`. It now returns `delay_interest` and `refund_interest` (interest only) and
`refund_total_with_interest`. Test extended in `tests/test_agent.py`. The hearing report and the
calculator page were not affected.

## 6. Rate limits on every costly route

`backend/app/auth/limits.py`, per signed-in user (per address for public routes): upload 40 / 10 min,
fact extraction 6 / 10 min, ask 20 / 10 min, passages 60 / min, agent 6 / 10 min, hearing 6 / 10 min,
order search 60 / min, classifier 30 / min, page pictures 240 / min, calculator 120 / min, stats 60 / min.
Still in-process: a second API server would need a shared store.

## 7. Smaller items

- `GET /api/v1/stats` (public): counts read from the database. The landing page uses it, so its
  figures can no longer go stale; the stale "2,019" on the sign-in pages is removed.
- `/docs` and `/openapi.json` are off when `NYAYASIM_COOKIE_SECURE=true` (production).
- Asking a question on a shared example case no longer writes to a history every user sees.
- The case list counts documents and facts only for the user's own cases.
- Agent and Ask pages rebuilt with shared evidence components (`frontend/components/evidence.tsx`).
- Website image now includes `public/` (`frontend/Dockerfile`); without it the example's page
  pictures would be missing in production.
- Steps closed for private cases are marked as such in the step rail.

## Not done

- Real buyers still cannot use fact extraction, cited answers, the agent or the hearing: that needs
  a model with a no-retention agreement (`NYAYASIM_PRIVATE_LLM_OK`).
- Uploads and page text are not encrypted at rest; there is no auto-expiry.
- The evaluation issues in `AUDIT_2026-11-15.md` section 6 (labels, split, leakage) are untouched.
- Background jobs still run in the API process; no queue or worker.
- The privacy page still has no grievance contact (it needs a real address from you).
- Highlights are not available on scanned pages.
- Pages were checked through their text and layout measurements, not by eye, because the browser
  window was hidden during this session.
